## 1. 교적관리 (Membership)

### 1-1. 교인 명부 / 현황
- [ ] 명부에 32명 표시, 검색(이름/전화 뒷자리/주소) 동작.
- [ ] 필터: 상태(재적/새가족/장기결석/전출), 직분, 신급, 연령대 — 각 필터 결과 정상.
  - 기대: 새가족 = 배지혜·남궁준·백지영, 장기결석 = 신광일, 전출 = 고은총.
- [ ] 교인 상세: 강선교 클릭 → 세대(강선교 가정)·가족(윤은혜 배우자, 강다니엘·강한별 자녀) 표시.
- [ ] 교적 현황 대시보드: 직분/신급/연령/상태 분포 그래프에 신규 데이터 반영.

### 1-2. 세대 · 가족
- [ ] 세대 목록 6개(+골든) 표시, 세대주·구역·주소 정상.
- [ ] 가족관계 양방향 확인(강선교↔윤은혜 배우자, 강선교→강다니엘 부모/자녀 역방향).
- [ ] 신규: 아무 교인에 가족관계 추가 → 반대편에 자동 반영되는지.

### 1-3. 직분 임명
- [ ] 임명 이력에 강선교(장로)·윤은혜(권사)·오믿음(안수집사) 표시.
- [ ] 신규 일괄 임명: 유하영 → '집사' 임명 → members.position 갱신 확인.

### 1-4. 출석
- [ ] '주일 1부 예배(테스트)' 예배에 2026-08-30 출석 12명(신광일 결석) 기록 확인.
- [ ] 신규 출석 입력(다른 날짜) → 저장·조회.

### 1-5. 심방 · 상담
- [ ] 심방 4건(강선교 가정심방, 홍성실 전화심방, 배지혜 새가족상담, 신광일 회복심방) 표시.
- [ ] 공개범위 '교역자 전용' 노출 정책 확인(권한 없는 계정에서 안 보이는지 — 계정 있으면).

### 1-6. 성례 · 이동
- [ ] 성례 5건(강다니엘 입교, 오예은 유아세례, 배지혜 세례, 남궁준 학습, 홍예찬 헌아식).
- [ ] 이동: 전입(조디모데, 뉴욕한인교회) / 전출(고은총, 애틀랜타소망교회).

### 1-7. 교적 코드
- [ ] 코드 드롭다운(직분/신급/상태 등)에 기본 코드셋 존재, 시드 값과 일치.
- [ ] 사용 중 코드 삭제 시 차단(409) 확인.

## 2. 스몰그룹 (Smallgroup)

### 2-1. 운영모델(프리셋)
- [ ] 현재 운영모델 확인(A 목장/B 구역/C 셀/D 사역별). 용어·리포트 항목이 화면에 반영.

### 2-2. 조직 (목장)
- [ ] 목장 4개 트리 표시, 목자/모임요일/장소 정상.
- [ ] 1-1목장이 **분가**(origin=1목장)로 계보 표시되는지.
- [ ] 신규 목장 생성 → 목자(교인 선택) 지정.

### 2-3. 배정
- [ ] 각 목장 조원 명단(위 표) 정확, 역할(목자/부목자/조원) 표시.
- [ ] 신규 배정: 무소속 교인(예: 유하영 → 다른 목장) 이동, 단일소속 정책(기존 소속 자동 종료) 확인.

### 2-4. 주간 리포트 / 모니터링
- [ ] 리포트 5건 표시(1·2목장 각 2, 3목장 1). 출석수 자동 계산 확인.
- [ ] 공개 나눔 vs 교역자 전용(care) 분리 노출.
- [ ] 리포트 모니터링: 미제출 목장 하이라이트, 주차별 제출률.
- [ ] 신규 리포트 작성 + 출석 체크 → 저장, 같은 목장·같은 날짜 재작성 시 upsert.

### 2-5. 교육
- [ ] 과정 2개(새가족반·제자훈련) + 차수 2개 표시.
- [ ] 수강: 새가족반(남궁준·백지영·배지혜), 제자훈련(윤은혜·오믿음·문사라).
- [ ] 회차 출결(1~2주차) 표시, 백지영 2주차 결석.
- [ ] 신규 수강 등록 + 회차 출결 입력 → 수료 처리(`수료`) 흐름.

### 2-6. 공지 / 자료실
- [ ] 공지 2건(목장 모임 안내[상단 고정]·제자훈련 개강), 대상범위(리더/전체) 표시.
- [ ] 자료실 2건(목장교재·새가족 가이드), 열람권한(리더/전체) 표시, 다운로드.

### 2-7. 배치 대기 큐
- [ ] 대기 2건: 백지영(새가족반 수료 예정, 교인 연결) / 이든호(홈페이지 문의, 미등록).
- [ ] 대기자 목장 배치(place) → 목장 조원으로 편입 확인.

## 3. 새가족 (Newcomer) — ⚠ 경로 이원화 점검

> 조사 결과: 새가족 유입 경로가 **둘**로 갈릴 수 있음.
> (a) 스토어프론트 **새가족 블록** → `newcomer_registrations` → **새가족 전용 관리 페이지**(`/t/dasom/newcomers`)
> (b) **폼빌더로 만든 '새가족 등록' 폼**(slug=newcomer) → `form_submissions` → **폼 제출 인박스**

- [ ] 스토어프론트 새가족 블록으로 등록 → 새가족 전용 페이지에 뜨는지(폼 제출엔 안 뜸).
- [ ] 폼빌더 '새가족 등록'으로 제출 → 폼 제출 인박스 '새가족' 필터에 뜨는지(전용 페이지엔 안 뜸).
- [ ] **판단**: 두 경로를 하나로 통합할지(권장: 새가족 폼도 전용 모듈로 수렴) 논의.
